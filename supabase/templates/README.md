# Branded auth emails

The HTML files here are generated by `node supabase/templates/build.mjs`; edit the script, not the output.
The logo is loaded from `{{ .SiteURL }}/community/nc-logo.png`, so set **Site URL** correctly in Supabase and make
sure the site is deployed (a PNG is used because many email clients do not render SVG).

## Apply in the dashboard
Authentication → **Email Templates**. For each tab paste the matching file and subject (see `subjects.txt`):

| Tab | File |
|---|---|
| Confirm signup | `confirmation.html` |
| Invite user | `invite.html` |
| Magic link | `magic_link.html` |
| Change email address | `email_change.html` |
| Reset password | `recovery.html` |
| Reauthentication | `reauthentication.html` |

## Or with the Supabase CLI (`supabase/config.toml`)
```toml
[auth.email.template.confirmation]
subject = "Confirm your Northwind Cipher account"
content_path = "./supabase/templates/confirmation.html"

[auth.email.template.recovery]
subject = "Reset your Northwind Cipher password"
content_path = "./supabase/templates/recovery.html"

[auth.email.template.magic_link]
subject = "Your Northwind Cipher sign-in link"
content_path = "./supabase/templates/magic_link.html"

[auth.email.template.invite]
subject = "You’re invited to Northwind Cipher"
content_path = "./supabase/templates/invite.html"

[auth.email.template.email_change]
subject = "Confirm your new email address"
content_path = "./supabase/templates/email_change.html"

[auth.email.template.reauthentication]
subject = "Your Northwind Cipher confirmation code"
content_path = "./supabase/templates/reauthentication.html"
```

## Deliverability (do this before launch)
The built-in Supabase mailer is limited to a few emails per hour and is not meant for production. Configure a custom
SMTP provider (Authentication → SMTP Settings) and set up SPF, DKIM and DMARC on your sending domain, otherwise
confirmation emails will land in spam or be rate-limited.
